# Painel de Publicações do Laboratório

## Frente 1 – Planilha (banco de dados)
1. No Google Drive do laboratório, crie (ou envie o Excel e abra como) uma Planilha Google com as colunas, nesta ordem:
   `Nome completo | Nível | Ano de ingresso | ORCID (opcional)`
2. Arquivo → Compartilhar → **Publicar na Web** → aba da planilha → formato **CSV** → Publicar. Copie o link.
3. Cada pessoa edita apenas a própria linha (compartilhe a planilha com permissão de edição ao grupo).

## Frente 2 – Página (GitHub Pages)
1. Crie um repositório no GitHub e envie `index.html` e este `README.md`.
2. Abra `index.html` e, no bloco `CONFIG`, cole o link CSV em `CSV_URL` (e, opcionalmente, seu e-mail).
3. Settings → Pages → Branch `main` / pasta `/ (root)` → Save.
4. A página ficará em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Observações
- Fonte das publicações: OpenAlex (gratuita, sem chave). Google Acadêmico, Scopus e Web of Science não têm API aberta utilizável no navegador.
- Preencher o ORCID evita confusão entre homônimos.
- O filtro usa publicações a partir de 1º de janeiro do ano de ingresso.
